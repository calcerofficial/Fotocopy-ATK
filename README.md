# CopyStream Pro - Sistem Informasi Fotokopi & ATK

CopyStream Pro adalah aplikasi desktop manajemen operasional untuk usaha fotokopi dan alat tulis kantor (ATK). Aplikasi ini dirancang untuk memudahkan pencatatan transaksi, pengolahan inventaris stok, serta penyajian laporan keuangan secara efisien dan terstruktur.

## 🚀 Fitur Utama
- **Dashboard Analytics:** Grafik penjualan bulanan, total pendapatan, dan pengeluaran secara real-time.
- **Manajemen Inventaris ATK:** Pengelolaan stok barang dan kategori layanan fotokopi.
- **Pencatatan Transaksi:** Form input transaksi kasir terintegrasi langsung ke basis data.
- **Manajemen Data & Laporan:** Penyimpanan riwayat transaksi dan pengeluaran harian/bulanan.

## 🛠️ Tech Stack
- **Language:** Java
- **UI Styling:** CSS
- **Database:** SQL / Relation Database System
